# @proofolio/contract-types

Owner: all three teams (generated from `contracts/`).

TypeScript types for every contract schema, generated by `make contracts-types` (KAN-7).
**Never edit `src/index.ts` by hand**: change the schema in `contracts/schemas/` and regenerate.
CI fails if the committed file is out of date.

Types only, no runtime code. Use them from the frontend or the render worker:

```ts
import type { WebsiteDraft, ErrorCode } from "@proofolio/contract-types";
```

Add it as a workspace dependency (`"@proofolio/contract-types": "file:../../packages/contract-types-ts"`).
For runtime validation use the JSON Schemas in `contracts/schemas/` with ajv.
