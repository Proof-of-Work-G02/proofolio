# services/_shared/python

Owner: AI team (Backend services import it too, so changes need an AI and a Backend reviewer).

Shared Python libraries for every Python service. Install into a service's environment with:

```sh
pip install -e services/_shared/python
```

| Package | What | Edited by hand? |
|---|---|---|
| `proofolio_contracts` | Pydantic models for every contract schema (KAN-7) | **No.** Generated by `make contracts-types` |
| `proofolio_worker` | Queue worker framework (AI-7) | Yes (not written yet) |
| `proofolio_llm` | LLM client (AI-9) | Yes (not written yet) |
